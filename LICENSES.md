# Asset and licensing notes

## Fonts

The project bundles local copies of:

- **DM Sans** — SIL Open Font License 1.1. Full upstream notice: `docs/DMSans-OFL.txt`.
- **DM Serif Display** — SIL Open Font License 1.1. Full upstream notice: `docs/DMSerifDisplay-OFL.txt`.
- **Noto Sans Devanagari** — SIL Open Font License 1.1. Full upstream notice: `docs/NotoSansDevanagari-OFL.txt`.

These bundled font files are in `public/assets/fonts/`. The upstream Google Fonts / font project licenses permit redistribution under the SIL Open Font License; retain the relevant notice when redistributing the fonts.

## Original portfolio media

- Images in `public/assets/` and `public/assets/posters/` were generated or assembled specifically for this portfolio. The poster copy was typeset separately with the bundled Devanagari font. Background images contain no generated lettering.
- `public/assets/videos/` contains original programmatic motion-graphics concepts assembled from local portfolio artwork. Sound beds were synthesized for these videos. No third-party song or stock footage is used.
- `public/assets/projects/*.svg` are original interface-preview illustrations authored for this portfolio. They illustrate concepts and are not product screenshots or third-party product marks.
- `scripts/` contains optional local generation code for the included media.

Unless a separate file-level license says otherwise, the original portfolio copy, design work and generated/assembled creative assets are provided for Harsh Takalkar's portfolio and remain attributed to Harsh Takalkar. No third-party stock-photo license is required for the included artwork. Third-party npm dependencies retain their own licenses; see their package metadata in `package-lock.json` / `node_modules` after installation.
